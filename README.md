# T-Lab RecSys

Решения заданий T-Lab по рекомендательным системам.

- **[Task 1](task1/)** - исследование методов генерации признаков для рекомендательных систем. CatBoost, OpenFE, AutoCross и DIN.
- **[Task 2](task2/)** - применение Reinforcement Learning для последовательных рекомендаций. GPT-2, Reward Model, RL и reranking.

Описание экспериментов, гипотезы, метрики и выводы приведены в соответствующих папках.
