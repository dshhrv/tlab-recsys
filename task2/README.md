# Исследование RL-подходов для последовательных рекомендаций

## Данные и протокол оценки

Эксперименты проведены на подвыборке **Yambda** из **300 пользователей**. Каталог ограничен **30 000 наиболее популярными объектами обучающей выборки**. Для каждого пользователя формируется последовательность взаимодействий, и модель должна предсказать следующий объект по предыдущей истории. Максимальная длина входной последовательности - **128 токенов**.

Взаимодействия разделены **глобально по времени** на train, validation и test в пропорции **8:1:1**. История для прогноза в момент $t$ содержит только события до `t`. На validation используется **GTS Last**, на test - **GTS Random** с **10 seed (42-51)**. Оценка проводится по всему выбранному каталогу из 30 000 объектов. **Повторные рекомендации разрешены**, поскольку повторное прослушивание трека может быть релевантным. Объекты за пределами каталога считаются промахами: на validation из 252 целевых взаимодействий 73 относятся к таким объектам.

Основные метрики - **Recall@20**, **NDCG@20** и **Coverage@20**. Дополнительно рассчитывается **Reward@20** как среднее предсказанное вознаграждение для рекомендованных объектов. В обучении используется reward model с seed 42, а для дополнительной оценки - отдельная модель с seed 44. Это независимый от оптимизируемой модели предиктор, обученный на тех же исходных данных, а не наблюдаемое вознаграждение пользователей.

Ниже финальные результаты **test** приведены в формате $\mathrm{mean} \pm \mathrm{std}$ по 10 GTS Random холдаутам**. Холдауты частично пересекаются, поэтому std отражает разброс по выбору тестовых взаимодействий, а не независимые запуски обучения.

## Исследуемые методы

1. **GPT-2 - базовая модель.** Небольшая авторегрессионная модель, обученная с нуля предсказывать следующий объект по последовательности предыдущих взаимодействий. Архитектура содержит 2 Transformer-блока, 4 attention-head и размер скрытого представления 128.
2. **Reward model.** Отдельная нейросеть по истории и объекту предсказывает три характеристики взаимодействия: долю прослушивания (`ratio`), длительность (`duration`) и положительную реакцию (`like`). В основных RL-экспериментах используется reward на основе `ratio`.
3. **GPT-2 + RL.** Модель дообучается с помощью группового REINFORCE по оценкам reward model. Исследуются KL-регуляризация относительно GPT-2, вспомогательная cross-entropy, учет релевантности при формировании reward и штраф за расхождение предсказаний ансамбля reward models.
4. **Reward-based reranking.** Перестановка кандидатов из top-100 GPT-2 с учетом оценок reward model. Исследуются мягкое смешивание с весом $\alpha$ и сортировка только по reward.

## Гипотезы

**H1. KL-регуляризация и дополнительная cross-entropy помогут увеличить reward без заметного снижения релевантности.** Ожидалось, что сохранение близости к исходной GPT-2 ограничит деградацию NDCG при RL-оптимизации.

**H3. Учет исходной релевантности GPT-2 при формировании reward улучшит качество RL.** Предполагалось, что сочетание reward model и оценок исходной модели позволит повысить Recall@20 и NDCG@20 по сравнению с RL без такого компонента.

**H4. Штраф за неопределенность ансамбля reward models улучшит устойчивость RL.** Предполагалось, что оптимизация $\operatorname{mean}(r) - \lambda \cdot \operatorname{std}(r)$ уменьшит переоптимизацию под отдельную reward model и позволит лучше сохранить качество ранжирования.

**H5. Мягкий reranking сможет увеличить предсказанный reward при небольших потерях релевантности.** Ожидалось, что небольшой вес reward model при перестановке top-100 будет лучше полной сортировки только по reward.

*Нумерация соответствует экспериментам. Отдельная гипотеза H2 о влиянии размера группы сэмплируемых действий не проверялась, поэтому выводы по ней не делаются.*

## Результаты

На validation reward model с seed 42 показала **RMSE = 0.4184** и **MAE = 0.3585** при прогнозировании доли прослушивания. Для постоянного прогноза соответствующие значения составляли **0.4456** и **0.4231**. Это подтверждает, что модель извлекает сигнал из истории, но само по себе не гарантирует улучшения рекомендаций при RL.

### Итоговое сравнение на test

| Модель | Recall@20 | NDCG@20 | Independent Reward@20 | Coverage@20 |
|---|---:|---:|---:|---:|
| GPT-2 | $0.1163 \pm 0.0153$ | $0.0653 \pm 0.0085$ | $0.6355 \pm 0.0026$ | **$0.1250 \pm 0.0015$** |
| GPT-2 + reranking ($\alpha = 0.3$) | $0.1141 \pm 0.0162$ | $0.0651 \pm 0.0099$ | **$0.6364 \pm 0.0026$** | $0.1239 \pm 0.0015$ |
| **GPT-2 + RL (H3, $\alpha = 0.3$)** | **$0.1216 \pm 0.0186$** | **$0.0660 \pm 0.0093$** | **$0.6364 \pm 0.0025$** | $0.1182 \pm 0.0017$ |

### RL-абляции на validation

Здесь приведены метрики **validation после 200 шагов** обучения. Для некоторых конфигураций лучший сохраненный checkpoint мог соответствовать другому шагу. `Predicted Reward` измеряется оптимизируемой reward model, `Independent Reward` - моделью с другим seed.

| Модель | Recall@20 | NDCG@20 | Predicted Reward@20 | Independent Reward@20 |
|---|---:|---:|---:|---:|
| GPT-2 | 0.146825 | 0.084495 | 0.631078 | 0.637662 |
| H1, CE + KL | 0.146825 | 0.084546 | 0.630558 | 0.637914 |
| H3, без учета релевантности | 0.142857 | 0.081984 | 0.632121 | 0.638326 |
| H3, вес релевантности 0.1 | **0.154762** | 0.083888 | 0.632641 | 0.638166 |
| **H3, вес релевантности 0.3** | 0.150794 | **0.084846** | **0.633016** | **0.638500** |
| H4, $\lambda = 0$ | 0.130952 | 0.079582 | 0.632184 | 0.638168 |
| H4, $\lambda = 0.5$ | 0.130952 | 0.078740 | 0.631907 | 0.638408 |
| H4, $\lambda = 1.0$ | 0.142857 | 0.081606 | 0.631909 | 0.638210 |

Для H1 критерий выбора checkpoint не обнаружил улучшения оптимизируемого reward при допустимом снижении NDCG, поэтому лучшим оставался исходный checkpoint (**step 0**).

## Выводы

**Лучшим проверенным RL-вариантом стала GPT-2 с учетом релевантности при формировании reward (H3, вес 0.3).** На test относительно исходной GPT-2 **Recall@20 вырос с 0.1163 до 0.1216 (+4.6%)**, а **NDCG@20 - с 0.0653 до 0.0660 (+1.1%)**. Independent Reward@20 также вырос с **0.6355 до 0.6364**. Однако **Coverage@20 снизился с 0.1250 до 0.1182**. Таким образом, небольшое улучшение качества ранжирования сопровождалось сокращением охвата каталога.

**Гипотеза H3 получила предварительное подтверждение.** На validation RL без учета релевантности дал **NDCG@20 = 0.081984**, а с весом релевантности 0.3 - **0.084846**. При этом Recall@20 вырос с **0.142857 до 0.150794**, а Independent Reward@20 - с **0.638326 до 0.638500**. Преимущество над исходной GPT-2 сохранилось и на test, но остается небольшим.

**Гипотеза H1 не подтвердилась.** Дополнительная cross-entropy и KL-регуляризация не обеспечили устойчивого прироста оптимизируемого reward. На 200-м шаге Predicted Reward@20 составлял **0.630558** против **0.631078** у GPT-2. Даже при небольшом изменении NDCG критерий выбора модели оставил лучшим исходный checkpoint.

**Гипотеза H4 не получила убедительного подтверждения.** При штрафе $\lambda = 1.0$ снижение NDCG оказалось меньше, чем без штрафа (**0.081606 против 0.079582** на 200-м шаге), однако все проверенные варианты H4 уступили H3 по NDCG и Recall. При $\lambda = 0.5$ Independent Reward немного увеличился, но NDCG снизился до **0.078740**. Сам по себе штраф за разброс оценок ансамбля не дал устойчивого улучшения.

**Гипотеза H5 подтвердилась только частично.** Мягкий reranking при $\alpha = 0.3$ на validation повысил Independent Reward@20 с **0.637662 до 0.638765**, но немного снизил NDCG@20 с **0.084495 до 0.083377**. На test его Reward@20 был выше базового (**0.6364 против 0.6355**), однако Recall@20 и NDCG@20 немного снизились. Полная сортировка по reward дала еще более высокий предсказанный reward, но резко ухудшила релевантность: **NDCG@20 = 0.021801**, **Recall@20 = 0.059524** на validation.

**Отдельный риск - переоптимизация под reward model.** При сортировке только по reward оценка оптимизируемой модели выросла с **0.631078 до 0.716237**, тогда как оценка другой reward model - лишь с **0.637662 до 0.642656**. Поэтому рост predicted reward нельзя автоматически считать улучшением фактических предпочтений пользователей.

В целом **RL с учетом релевантности оказался наиболее удачным компромиссом между reward и качеством рекомендаций** на выбранной подвыборке Yambda. При этом улучшения невелики относительно разброса результатов между холдаутами, а независимая reward model обучена на тех же данных. Для утверждений о статистической значимости или росте реального пользовательского вознаграждения необходимы дополнительные проверки на одинаковых запросах и более крупной выборке.
